# Plumber Quote App — Specification Pack

This folder contains the initial V1 planning files for the plumber quotation PWA.

## Files

- `PRODUCT.md` — authoritative V1 product specification
- `BUILD_PLAN.md` — milestone-by-milestone implementation roadmap
- `CODEX_RULES.md` — implementation constraints and working rules for Codex

## Recommended project placement

Place the files in your repository like this:

```text
project-root/
├─ AGENTS.md
└─ docs/
   ├─ PRODUCT.md
   ├─ BUILD_PLAN.md
   └─ CODEX_RULES.md
```

A minimal `AGENTS.md` can instruct Codex to read the three files before beginning any milestone.
