# Plumber Quote App — Codex Instructions

Before implementing any milestone:

1. Read `docs/PRODUCT.md`.
2. Read `docs/BUILD_PLAN.md`.
3. Read `docs/CODEX_RULES.md`.
4. Treat the files in `docs/` as authoritative product and implementation specifications.
5. Identify the currently assigned milestone in `docs/BUILD_PLAN.md`.
6. Implement only that milestone.
7. Do not silently change accepted product behaviour, workflow, storage strategy, PDF requirements, or V1 scope.
8. If you find a genuine contradiction or implementation blocker, report it explicitly before making a product-level change.
9. Run the relevant checks required by the milestone.
10. Stop after completing and reporting the assigned milestone.

The V1 product has one primary workflow:

`Create Quote → Generate PDF → Send or Print`

Do not introduce features outside the documented V1 scope unless the specification is explicitly updated first.
